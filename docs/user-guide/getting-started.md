# Getting Started with ADFIR

## Quick Start
1. Launch backend and desktop interface:
   ```bash
   cd ~/ADFIR
   ./scripts/start_dev.sh
   ```
2. Navigate to **Investigation** -> Click **New Investigation**.
3. In **Evidence**, enter the absolute path to your disk image or test evidence file -> Click **Calculate SHA-256 & Ingest**.
4. In **Findings**, view deterministic tool artifacts, run **Correlation & Verification**.
5. In **Reports**, synthesize the complete 19-section forensic report and export to Markdown.
